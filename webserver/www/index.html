INSIDE THE SERVER — the syscalls that answered you

~250 lines of C in one file. No dependencies. Here is the path your request took:

  1. socket(AF_INET, SOCK_STREAM, 0) — kernel, give me a TCP socket
  2. bind() + listen() — claim port 8080 and wait
  3. accept() — kernel finished the handshake (rows 1–3) and hands over the connection
  4. read() — bytes arrive (row 4); read until "\r\n\r\n" ends the headers
  5. sscanf() — parse "GET / HTTP/1.1", map "/" → www/index.html, guard against "../"
  6. fopen() — this very file; ftell() gives the Content-Length
  7. send_all() — headers, then chunks; a loop, because send() may write partially
  8. close() — row 6. this connection existed to deliver exactly one page: the one you're reading
